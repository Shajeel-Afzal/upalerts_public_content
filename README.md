# UpAlerts Public Content

This repository contains public assets and resources for the UpAlerts project.

## Contents

### Sample AI Images

The `sample_ai_images/` directory contains sample images that can be referenced via URL in other projects:

- `style_1.png` - AI generated style sample 1
- `style_2.png` - AI generated style sample 2
- `style_3.png` - AI generated style sample 3

## Usage

You can reference these images directly via GitHub's raw content URLs:

```
https://raw.githubusercontent.com/YOUR_USERNAME/upalerts_public_content/main/sample_ai_images/style_1.png
https://raw.githubusercontent.com/YOUR_USERNAME/upalerts_public_content/main/sample_ai_images/style_2.png
https://raw.githubusercontent.com/YOUR_USERNAME/upalerts_public_content/main/sample_ai_images/style_3.png
```

Replace `YOUR_USERNAME` with your GitHub username once the repository is published.
